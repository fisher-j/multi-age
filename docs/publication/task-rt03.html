RT03 - fuel Results narrative

Status: Pending review. Working target: 1.5–2 manuscript pages.

Purpose, inputs, and scope

With the fuel estimates assembled, we’ll work out which patterns the Results should report and how to describe their uncertainty. This page draws on the F01 component/model record and RD04 inference and display record. The F01 and RD04 task pages own their execution order and handoff. The shared sections/results.qmd assembles the Results; RT03 maintains the shared fuel subsection in sections/fuel-results.qmd.

Results subsection in the working manuscript reports phase-specific fuel reference means followed by the matched woody standing-vegetation contrast. Its working allocation is 1.5–2 manuscript pages, approximately 500 words excluding the figure, table, captions, and review note; final pagination depends on journal formatting.

Implemented source and review decisions

Source or finding Implementation in RT03
Thesis analysis/thesis/results.qmd, fuel subsections Retain the pre-PCT, post-PCT, and vegetation-transition sequence, using current publication values throughout.
Revised component definitions Report woody and herbaceous vegetation separately; distinguish modeled litter and duff before PCT; omit post-PCT forest-floor estimates.
RD04 inference review Use equally site-weighted, random-effect-integrated arithmetic mean loads including zeros, rather than the thesis zero-random-effect references.
Joint woody phase model Report its four pre-minus-post mean reductions and covariance-aware confidence intervals, consistent with the woody load panel. Do not use the separate Student-t difference-model estimates.
Thesis significance and causal wording Replace inherited p-values with descriptive treatment rankings. Report exclusion of zero only for the four computed woody-change intervals; dead-fuel phase comparisons have no paired-change tests here.
Slash and design interpretation Describe potential surface-fuel contribution, not measured slash deposition; avoid attributing the entire phase transition to PCT.
Numerical provenance Draw inline narrative values and the shared companion table from rd04-fuel-model-estimates.csv; do not carry forward the unsourced coarse-wood grand mean noted in the audit.

Review products: the fuel Results draft and existing nine-panel figure and caption. The companion values table is accepted for the publication supplement; its source is sections/rd04-fuel-estimates-table.qmd.

Acceptance tests: each quantitative claim is traceable to the current figure/CSV; point-estimate rankings are not presented as pairwise tests; intervals describe uncertainty in means, not new-transect variation; the standing-woody contrast is not a direct slash measure or an isolated causal PCT effect. Scientific model acceptance and narrative review remain open. Acceptance of the supplementary table does not mark RT03 accepted or complete.

Implications and handoff

The RD04 CSV remains the numerical source for inline values; RT03 does not recalculate inference or redefine its estimand. Upstream changes require a fresh review of affected claims here. M03 will describe the accepted fuel methods and D03 will own the management interpretation once their queued work begins. Neither task is completed or accepted by the narrative draft.

Draft Results and numerical source

The hidden setup loads the shared F01 helpers and enables automatic chunk labels before any code is displayed.

The Results values need to stay aligned with the figure as the analysis develops. We’ll read the saved RD04 means and intervals and format them for inline use, without recalculating inference. The saved formatter carries those estimates with it and is refreshed on each render. The draft below puts the values in context, moving from phase-specific fuel conditions to matched woody change.

Code 
# rt03-fuel-narrative-values
fuel_results <- read.csv(
  "outputs/fuel/tables/rd04-fuel-model-estimates.csv",
  stringsAsFactors = FALSE
)
fuel_components <- c(
  one = "1-hour fuel",
  ten = "10-hour fuel",
  hundred = "100-hour fuel",
  coarse = "1,000-hour fuel",
  woody = "Woody vegetation",
  herb = "Herbaceous vegetation",
  litter = "Litter (pre-PCT only)",
  duff = "Duff (pre-PCT only)",
  reduction = "Woody vegetation difference (pre-PCT minus post-PCT)"
)
fuel_phases <- c(
  pre = "Pre-PCT",
  post = "Post-PCT",
  change = "Vegetation difference"
)
fuel_value <- function(
  component,
  phase,
  treatment,
  interval = FALSE,
  digits = 1L
) {
  cell <- fuel_results[
    fuel_results$component == fuel_components[[component]] &
      fuel_results$phase == fuel_phases[[phase]] &
      fuel_results$treatment == treatment,
  ]
  stopifnot(nrow(cell) == 1L)
  value <- formatC(cell$estimate, format = "f", digits = digits)
  if (interval) {
    value <- paste0(
      value,
      " (95% CI ",
      formatC(cell$lcl, format = "f", digits = digits),
      " to ",
      formatC(cell$ucl, format = "f", digits = digits),
      ")"
    )
  }
  value
}

# Save the function with the data it uses so other pages can render inline values.
environment(fuel_value) <- list2env(list(fuel_results = fuel_results,
  fuel_components = fuel_components, fuel_phases = fuel_phases), parent = baseenv())
dir.create("outputs/helpers", recursive = TRUE, showWarnings = FALSE)
saveRDS(fuel_value, "outputs/helpers/fuel-value.rds")

Fuel conditions before and after precommercial thinning

Dead fuel loading

Fuel measurements ten years after harvest characterized conditions before and after precommercial thinning (PCT) across the four retention treatments (Figure 1). Following PCT, group selection (GS) and low-density dispersed retention (LD) showed the largest estimated increases in fine dead-fuel loads and reductions in woody standing vegetation. These treatments also had the highest post-PCT fine dead-fuel loads. Pre-PCT dead-fuel estimates suggested subtler, component-specific treatment patterns. Fuel loads are reported as model-estimated means, with 95% confidence intervals. Woody and herbaceous standing vegetation are reported separately, as are pre-PCT litter and duff. All loads and load differences below are in Mg ha-1.

Before PCT, estimated 1-hour fuel loads were highest in high-density aggregated retention (HA; 1.2) and lowest in GS (0.6), with LD and high-density dispersed (HD) retention intermediate. Estimated 10-hour loads ranged from 2.8 in HD to 3.8 in GS, and 100-hour loads from 9.0 to 11.5 in those same treatments. The 1,000-hour class had larger mean loads, ranging from 30.2 in LD to 49.6 (95% CI 25.9 to 95.0) in GS. Uncertainty was substantial for this coarse-wood component across treatments.

The separated forest-floor components showed different treatment patterns. Pre-PCT litter estimates ranged from 12.6 in LD to 18.4 in GS; HA and HD were intermediate. Duff estimates were lowest in HA, at 19.3 (95% CI 14.5 to 25.8), and highest in HD, at 35.5 (95% CI 26.6 to 47.4), with GS and LD both near 28–29. These are model-derived forest-floor loads based on the estimated litter-depth boundary. Post-PCT litter and duff were not estimated because the forest-floor boundary could not be distinguished reliably in the presence of slash and suspended foliage.

After PCT, estimated 1-hour loads were about 2.4–2.7 in GS, LD, and HD, and 1.4 in HA. The 10-hour estimates were ordered GS (9.6), LD (5.9), HA (4.1), and HD (3.3). The 100-hour estimates followed the same order, from 19.6 (95% CI 11.8 to 32.8) in GS to 7.5 (95% CI 4.6 to 12.2) in HD. Post-PCT 1,000-hour means ranged from 25.2 in HA to 53.9 in GS, with wide confidence intervals. These rankings describe estimated loads; they do not establish pairwise treatment differences. The separate dead-fuel phase estimates are reference conditions, without paired phase-change tests in this display.

Standing vegetation and woody vegetation difference

Pre-PCT woody standing-vegetation means were greatest in GS (39.9), followed by LD (26.5), HD (18.8), and HA (14.7). Post-PCT means were 2.0–2.9 across treatments. The joint phase model estimated pre-minus-post reductions of 37.4 (95% CI 13.4 to 61.4) in GS, 24.5 (95% CI 9.0 to 40.0) in LD, 11.8 (95% CI 3.6 to 20.0) in HA, and 16.6 (95% CI 5.5 to 27.6) in HD. All four reduction intervals excluded zero. Their uncertainty includes the pre/post covariance; the ordering of reduction estimates alone does not test differences among treatments.

Herbaceous standing-vegetation means were small relative to woody loads: 0.24–0.59 before PCT and 0.11–0.35 afterward, with broad relative uncertainty. The woody reduction represents an inferred potential contribution to surface fuels. It does not measure slash deposition or reconcile standing-vegetation loss with changes in downed fuel classes. Without a contemporaneous unthinned comparison, the phase transition does not isolate a causal PCT effect.
