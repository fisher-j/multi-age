F01 — fuel-component separation and model exploration

Status: Completed — analytical record. Working target: Reproducible component/model record.

Original objective and guardrails

Create publication-only fuel components that preserve the thesis analyses while making the pre- and post-PCT data usable as distinct reference phases. Retain the fixed experimental-design random-intercept structure; record every model candidate and diagnostic; do not treat an AIC leader as a selected model.

  • Thesis notebooks, raw data, and thesis-era .rda objects remain unchanged.
  • Pre-PCT litter and duff are separated using the Finney–Martin model-3 forest-floor partition; post-PCT litter and duff are deliberately omitted because their boundary is not currently defensible.
  • Woody and herbaceous vegetation are separate in both phases.
  • The primary PCT contrast is matched-transect pre-PCT minus post-PCT woody standing vegetation—an inferred potential surface-fuel contribution, not a direct slash-load measurement.

Decisions made

Decision area Recorded decision Why it matters for the publication display
Reporting phases Show pre- and post-PCT values as distinct phases. Avoids treating the contrast as automatically causal.
Forest floor Report modeled litter and duff only before PCT. Prevents a misleading post-PCT forest-floor estimate.
Vegetation Keep woody and herbaceous components separate. Allows the PCT-related standing-woody change to remain visible.
PCT estimand Use matched pre minus post woody standing vegetation. Clearly labels the management contrast and its limitation.
Model selection Preserve all candidates; leaders are provisional pending scientific review. Keeps model choice auditable instead of hiding it in a final table.

Publication fuel-analysis pipeline

This directory is a publication-only branch of the thesis fuel workflow. It must not alter raw data, the thesis notebooks, or thesis-era .rda objects.

01-derive-components.R reads summarize_collected_data.rda as a read-only input. It carries the unchanged 1-, 10-, 100-, and 1,000-hour components from the read-only thesis calculate_fuel_load.rda object, but does not use that object’s combined duff/litter or vegetation columns. It writes only beneath outputs/publication/fuel/.

Current analytical decisions:

  • Pre-PCT litter and duff are separate, model-derived forest-floor components. The script uses Finney and Martin (1993), model 3, with the recorded total forest-floor depth and estimated litter percentage. A negative value from a shallow extrapolation is bounded at zero and retained in the station-level audit output.
  • Post-PCT duff and litter loads are deliberately not calculated or reported: slash and suspended green foliage make the forest-floor boundary ambiguous.
  • Woody and herbaceous vegetation remain separate in both phases.
  • The primary PCT contrast is matched-transect pre-PCT minus post-PCT woody standing vegetation. It is an inferred potential surface-fuel contribution, not a direct slash-load measurement.
  • Fuel-bed depth is retained for a later protocol-comparability review and is not yet interpreted as slash depth.

No model family, dispersion structure, zero process, or random-effects selection is made by the derivation script. 02-explore-components.R fixes the random-intercept structure dictated by the design: site, site-by-treatment block, and corner nested within block. It reports zeros and spread by component and proposes zero-inflation and dispersion candidates without fitting models.

The fitting scripts preserve every attempted candidate in a model registry with its formula, family, zero and dispersion formulas, warnings, AIC, and DHARMa tests. 05-evaluate-and-select-models.R identifies only provisional AIC leaders; final selection requires documented diagnostic and scientific review.

publication_fuel_paths <- function(analysis_root) {
  list(
    input = file.path(analysis_root, "summarize_collected_data.rda"),
    legacy_load_input = file.path(analysis_root, "calculate_fuel_load.rda"),
    output = file.path(analysis_root, "outputs", "publication", "fuel"),
    data = file.path(analysis_root, "outputs", "publication", "fuel", "data"),
    manifests = file.path(
      analysis_root,
      "outputs",
      "publication",
      "fuel",
      "manifests"
    )
  )
}

publication_fuel_ids <- c("site", "treatment", "corner", "azi")

# Finney and Martin (1993), model 3: cumulative forest-floor mass (Mg ha^-1)
# from the surface to depth ds_cm within a profile of total depth dp_cm.
# The model is used only for the pre-PCT forest-floor measurements, where the
# recorded total depth and estimated litter proportion describe the forest floor.
# Its fitted range does not support a negative cumulative mass; the derivation
# script records and bounds such rare shallow-layer extrapolations at zero.
finney_martin_cumulative_load <- function(ds_cm, dp_cm) {
  result <- 6.461 * ds_cm^1.07 - 0.254 * dp_cm
  result[ds_cm == 0] <- 0
  result
}

    total_forest_floor_depth_cm = duff_litter,
    estimated_litter_fraction = pct_litter / 100,
    estimated_litter_depth_cm = total_forest_floor_depth_cm * estimated_litter_fraction,
    estimated_duff_depth_cm = total_forest_floor_depth_cm - estimated_litter_depth_cm,

# Finney and Martin's cumulative curve partitions the pre-PCT total profile at
# the estimated litter/duff boundary. These are model-derived loads, not direct
# independent bulk-density measurements of the two layers.
forest_floor_pre_station <- forest_floor_station |>
  filter(forest_floor_load_eligible) |>
  mutate(
    total_forest_floor_load_mgha = finney_martin_cumulative_load(
      total_forest_floor_depth_cm,
      total_forest_floor_depth_cm
    ),
    litter_load_mgha = finney_martin_cumulative_load(
      estimated_litter_depth_cm,
      total_forest_floor_depth_cm
    ),
    litter_load_raw_mgha = litter_load_mgha,
    litter_load_bounded_at_zero = litter_load_raw_mgha < 0,
    litter_load_mgha = pmax(litter_load_raw_mgha, 0),
    duff_load_mgha = total_forest_floor_load_mgha - litter_load_mgha
  )

if (any(forest_floor_pre_station$duff_load_mgha < 0, na.rm = TRUE)) {
  stop("Finney-Martin component calculation produced a negative duff load; inspect the input depths before proceeding.")
}

add_design_groups <- function(data) {
  data |>
    mutate(
      block = interaction(site, treatment, drop = TRUE),

  summarise(

    n_zero = sum(load_mgha == 0, na.rm = TRUE),
    prop_zero = mean(load_mgha == 0, na.rm = TRUE),
    n_missing = sum(is.na(load_mgha)),
    mean_mgha = mean(load_mgha, na.rm = TRUE),
    sd_mgha = sd(load_mgha, na.rm = TRUE),
    variance_mgha = var(load_mgha, na.rm = TRUE),
    cv = if_else(mean_mgha > 0, sd_mgha / mean_mgha, NA_real_),
    min_mgha = min(load_mgha, na.rm = TRUE),
    q25_mgha = quantile(load_mgha, 0.25, na.rm = TRUE, names = FALSE),
    median_mgha = median(load_mgha, na.rm = TRUE),
    q75_mgha = quantile(load_mgha, 0.75, na.rm = TRUE, names = FALSE),

model_output_paths <- function(paths) {

  diagnostics <- file.path(paths$output, "diagnostics")
  dir.create(models, recursive = TRUE, showWarnings = FALSE)

}

extract_test <- function(test_fun, simulation) {
  result <- tryCatch(test_fun(simulation), error = function(error) error)
  if (inherits(result, "error")) {
    return(list(statistic = NA_real_, p_value = NA_real_, error = conditionMessage(result)))
  }
  list(
    statistic = unname(result$statistic)[1],
    p_value = result$p.value,
    error = NA_character_
  )
}

fit_and_diagnose <- function(
    model_id,
    response,
    analysis,
    data,
    formula,
    family,
    family_label,
    ziformula,
    ziformula_label,
    dispformula,
    dispformula_label,
    paths) {
  output_paths <- model_output_paths(paths)
  warnings <- character()
  fit <- tryCatch(
    withCallingHandlers(
      glmmTMB::glmmTMB(
        formula = formula,
        data = data,
        family = family,
        ziformula = ziformula,
        dispformula = dispformula
      ),
      warning = function(warning) {
        warnings <<- c(warnings, conditionMessage(warning))
        invokeRestart("muffleWarning")
      }
    ),
    error = function(error) error
  )

  base_record <- tibble::tibble(
    model_id = model_id,
    response = response,
    analysis = analysis,
    n = nrow(data),
    fixed_and_random_formula = paste(deparse(formula), collapse = " "),
    family = family_label,
    ziformula = ziformula_label,
    dispformula = dispformula_label,
    fit_status = if (inherits(fit, "error")) "error" else "fit",
    fit_message = if (inherits(fit, "error")) conditionMessage(fit) else NA_character_,
    warnings = if (length(warnings)) paste(unique(warnings), collapse = " | ") else NA_character_,
    pd_hessian = NA,
    aic = NA_real_,
    dharma_uniformity_p = NA_real_,
    dharma_dispersion_p = NA_real_,
    dharma_outlier_p = NA_real_,
    dharma_zero_inflation_p = NA_real_,
    diagnostic_message = NA_character_
  )

  if (inherits(fit, "error")) {
    return(base_record)
  }

  saveRDS(fit, file.path(output_paths$models, paste0(model_id, ".rds")))
  simulation <- tryCatch(
    DHARMa::simulateResiduals(fit, n = 1000, seed = 20260918),
    error = function(error) error
  )
  if (inherits(simulation, "error")) {
    return(dplyr::mutate(
      base_record,
      pd_hessian = fit$sdr$pdHess,
      aic = stats::AIC(fit),
      diagnostic_message = conditionMessage(simulation)
    ))
  }

  # Some DHARMa tests may draw internally. Use a null device so these
  # exploratory diagnostics never create an incidental Rplots.pdf in analysis/.
  grDevices::pdf(file = NULL)
  on.exit(grDevices::dev.off(), add = TRUE)
  uniformity <- extract_test(DHARMa::testUniformity, simulation)
  dispersion <- extract_test(DHARMa::testDispersion, simulation)
  outliers <- extract_test(DHARMa::testOutliers, simulation)
  zero_inflation <- extract_test(DHARMa::testZeroInflation, simulation)

  png(
    filename = file.path(output_paths$diagnostics, paste0(model_id, "-dharma.png")),
    width = 1800,
    height = 900,
    res = 150
  )
  plot(simulation)
  dev.off()

  dplyr::mutate(
    base_record,
    pd_hessian = fit$sdr$pdHess,
    aic = stats::AIC(fit),
    dharma_uniformity_p = uniformity$p_value,
    dharma_dispersion_p = dispersion$p_value,
    dharma_outlier_p = outliers$p_value,
    dharma_zero_inflation_p = zero_inflation$p_value,
    diagnostic_message = paste(
      stats::na.omit(c(uniformity$error, dispersion$error, outliers$error, zero_inflation$error)),
      collapse = " | "
    )
  )
}

# Keep valid nested identifiers from one observed row per site/treatment/phase.
# These identifiers do not contribute fitted random effects when re.form=NA.
reference_grid <- function(model, phase = NULL) {
  keys <- intersect(c("site", "treatment", "phase"), names(model$frame))
  grid <- distinct(model$frame, across(all_of(keys)), .keep_all = TRUE)
  if (!is.null(phase) && "phase" %in% keys) grid <- filter(grid, .data$phase == .env$phase)
  counts <- count(grid, treatment)
  stopifnot(length(unique(counts$n)) == 1L)
  grid
}

# A maps row predictions to equally weighted site means. A V A' retains every
# cross-site covariance; treating site predictions as independent is incorrect.
averaging_matrix <- function(grid) {
  keys <- intersect(c("treatment", "phase"), names(grid))
  labels <- distinct(grid, across(all_of(keys)))
  A <- t(vapply(seq_len(nrow(labels)), function(i) {
    keep <- Reduce(`&`, lapply(keys, function(k) grid[[k]] == labels[[k]][i]))
    as.numeric(keep) / sum(keep)
  }, numeric(nrow(grid))))
  list(A = A, labels = labels)
}

custom_reference <- function(model, grid) {
  p <- predict(model, newdata = grid, type = "response", re.form = NA,
               allow.new.levels = TRUE, se.fit = TRUE, cov.fit = TRUE)
  avg <- averaging_matrix(grid)
  transform(avg$labels, estimate = as.vector(avg$A %*% p$fit),
            std.error = sqrt(diag(avg$A %*% p$cov.fit %*% t(avg$A))))
}

# Exact integration for THESE models: independent Gaussian random intercepts in
# the conditional model, log/identity link, no random effects in the zero model.
# This deliberately fails on slopes, correlated effects, offsets, or other links.
integration_setup <- function(model, grid) {
  vc <- VarCorr(model)
  stopifnot(length(vc$zi) == 0L, length(vc$disp) == 0L,
            all(vapply(vc$cond, function(x) identical(dim(x), c(1L, 1L)), logical(1))))
  X <- model.matrix(delete.response(terms(formula(model, fixed.only = TRUE))), grid)
  Z <- model.matrix(formula(model, component = "zi", fixed.only = TRUE), grid)
  par <- model$fit$par
  ib <- which(names(par) == "beta")
  iz <- which(names(par) == "betazi")
  it <- which(names(par) == "theta")
  stopifnot(ncol(X) == length(ib), ncol(Z) == length(iz),
            length(it) == length(vc$cond), model$sdr$pdHess,
            isTRUE(all.equal(unname(par), unname(model$sdr$par.fixed))),
            is.null(model.offset(model$frame)),
            family(model)$link %in% c("log", "identity"))
  variance <- sum(vapply(vc$cond, function(x) x[1, 1], numeric(1)))
  stopifnot(isTRUE(all.equal(variance, sum(exp(2 * par[it])), tolerance = 1e-8)))
  list(X = X, Z = Z, par = par, V = model$sdr$cov.fixed,
       ib = ib, iz = iz, it = it, link = family(model)$link,
       avg = averaging_matrix(grid), variance = variance)
}

# Independent analytic derivatives for the custom delta-method implementation.
custom_integrated <- function(s) {
  eta <- drop(s$X %*% s$par[s$ib])
  pzero <- if (length(s$iz)) plogis(drop(s$Z %*% s$par[s$iz])) else rep(0, length(eta))
  if (s$link == "log") {
    mu <- exp(eta + s$variance / 2) * (1 - pzero)
    D <- matrix(0, nrow(s$X), length(s$par))
    D[, s$ib] <- mu * s$X
    if (length(s$iz)) D[, s$iz] <- -mu * pzero * s$Z
    D[, s$it] <- outer(mu, exp(2 * s$par[s$it]))
  } else {
    stopifnot(length(s$iz) == 0L)
    mu <- eta
    D <- matrix(0, nrow(s$X), length(s$par))
    D[, s$ib] <- s$X
  }
  G <- s$avg$A %*% D
  list(estimate = drop(s$avg$A %*% mu),
       se = sqrt(pmax(0, diag(G %*% s$V %*% t(G)))), G = G)
}

# Contrast the same matched model's integrated phase means, retaining their
# covariance through a single gradient and the full parameter covariance.
woody_change_setup <- function(s) {
  labels <- s$avg$labels
  stopifnot(all(c("phase", "treatment") %in% names(labels)),
            setequal(unique(as.character(labels$phase)), c("prepct", "postpct")))
  treatments <- unique(as.character(labels$treatment))
  C <- t(vapply(treatments, function(trt) {
    stopifnot(sum(labels$treatment == trt & labels$phase == "prepct") == 1L,
              sum(labels$treatment == trt & labels$phase == "postpct") == 1L)
    as.numeric(labels$treatment == trt) * ifelse(labels$phase == "prepct", 1, -1)
  }, numeric(nrow(labels))))
  s$avg$A <- C %*% s$avg$A
  s$avg$labels <- data.frame(treatment = treatments)
  s
}

# marginaleffects does the nonlinear delta method on a supplied full parameter
# table, including theta (log SDs), not just the conditional fixed coefficients.
# avg_predictions(re.form=NA) alone does NOT integrate over random effects.
marginaleffects_integrated <- function(s) {
  parameters <- data.frame(term = paste0("p", seq_along(s$par)),
                           estimate = unname(s$par))
  functional <- function(x) {
    b <- x$estimate
    eta <- drop(s$X %*% b[s$ib])
    pzero <- if (length(s$iz)) plogis(drop(s$Z %*% b[s$iz])) else rep(0, length(eta))
    mu <- if (s$link == "log") exp(eta + sum(exp(2 * b[s$it])) / 2) * (1 - pzero) else eta
    data.frame(term = seq_len(nrow(s$avg$labels)), estimate = drop(s$avg$A %*% mu))
  }
  marginaleffects::hypotheses(parameters, hypothesis = functional, vcov = s$V,
             numderiv = "fdcenter", conf_level = .95)
}
