F01 - fuel-component separation and model exploration

Status: Completed - analytical record. Working target: Reproducible component/model record.

We want to describe fuel conditions under the four overstory treatments before and after PCT, and explore what the change in standing woody vegetation can tell us about potential additions to surface fuels. Here we’ll derive the components, examine their distributions, and compare candidate models. The saved fits then feed RD04 inference and display and RT03 Results writing.

Original objective and guardrails

Create publication-only fuel components that preserve the thesis analyses while making the pre- and post-PCT data usable as distinct reference phases. During model fitting, retain the prescribed experimental-design random-intercept structure; record every model candidate and diagnostic; do not treat an AIC leader as a selected model.

  • Thesis notebooks, raw data, and thesis-era .rda objects remain unchanged.
  • Pre-PCT litter and duff are separated using the Finney–Martin model-3 forest-floor partition; post-PCT litter and duff are deliberately omitted because their boundary is not currently defensible.
  • Woody and herbaceous vegetation are separate in both phases.
  • The primary PCT contrast is matched-transect pre-PCT minus post-PCT woody standing vegetation - an inferred potential surface-fuel contribution, not a direct slash-load measurement.

read_saved_model <- function(path, task) {
  if (!file.exists(path)) {
    stop(
      "Missing saved model: ",
      path,
      ". Run quarto render task-",
      tolower(task),
      ".qmd -P refit:true"
    )
  }
  model <- readRDS(path)
  # Saved glmmTMB calls can refer to a former session's local data name.
  # Predictions and residual checks should use the model's stored rows instead.
  if (inherits(model, "glmmTMB")) {
    model$call$data <- model$frame
  }
  model
}

# f01-table-functions
# Show two significant figures, retaining trailing zeros below one and avoiding
# scientific notation. Round before formatting so large values are rounded too.
publication_number <- function(x, digits = 2L) {
  value <- trimws(formatC(
    signif(x, digits),
    format = "fg",
    digits = digits,
    flag = "#"
  ))
  value <- sub("\\.$", "", value)
  value[is.na(x)] <- NA_character_
  value
}

# Allow model identifiers to wrap without changing their saved values.
publication_model_id <- function(x) {
  gsub("_", " ", x, fixed = TRUE)
}

# Use the same controls for analytical results and CSV review tables.
# Keep the supplied order until a reader sorts, and escape data by default so
# formulas and HTML-like text remain literal. Integer counts stay exact;
# AIC uses whole numbers; other continuous columns use significant figures.
publication_table <- function(data, digits = 2L, caption = NULL) {
  model_ids <- names(data) %in% c(
    "model_id", "component_model_id", "provisional_aic_leader", "Provisional leader"
  )
  data[model_ids] <- lapply(data[model_ids], publication_model_id)
  if (!is.null(digits)) {
    numeric <- vapply(
      data,
      function(x) is.numeric(x) && !is.integer(x),
      logical(1)
    )
    aic <- numeric & tolower(names(data)) == "aic"
    data[aic] <- lapply(data[aic], function(x) {
      value <- formatC(round(x), format = "f", digits = 0L)
      value[is.na(x)] <- NA_character_
      value
    })
    data[numeric & !aic] <- lapply(
      data[numeric & !aic],
      publication_number,
      digits = digits
    )
  }
  DT::datatable(
    data,
    rownames = FALSE,
    escape = TRUE,
    caption = caption,
    extensions = "Buttons",
    selection = "none",
    width = "100%",
    options = list(
      dom = "B l f r t i p",
      order = list(),
      ordering = TRUE,
      searching = TRUE,
      scrollX = TRUE,
      pageLength = 10,
      lengthMenu = list(c(10, 25, 50, -1), c("10", "25", "50", "All")),
      buttons = list(list(extend = "colvis", text = "Show/hide fields"))
    )
  )
}

01 - Derive components and audit pairing

Before comparing treatments, we need fuel components that have a defensible meaning in each measurement phase. We’ll start by partitioning the pre-PCT forest floor into litter and duff with Finney–Martin model 3. The summary below shows the resulting loads and how often shallow-layer extrapolations needed to be bounded at zero. We’ll leave post-PCT litter and duff out because their boundary cannot currently be identified reliably.

Code 
# f01-01-derive-components
if (recompute) {
  # Finney and Martin (1993), model 3: cumulative forest-floor mass (Mg ha^-1)
  # from the surface to depth ds_cm within a profile of total depth dp_cm.
  # The model is used only for the pre-PCT forest-floor measurements, where the
  # recorded total depth and estimated litter proportion describe the forest floor.
  # Its fitted range does not support a negative cumulative mass; the derivation
  # script records and bounds such rare shallow-layer extrapolations at zero.
  finney_martin_cumulative_load <- function(ds_cm, dp_cm) {
    result <- 6.461 * ds_cm^1.07 - 0.254 * dp_cm
    result[ds_cm == 0] <- 0
    result
  }

  publication_root <- normalizePath(getwd(), winslash = "/")
  paths_common <- publication_paths(publication_root)

  library(dplyr)
  library(readr)
  library(tidyr)

  paths <- publication_fuel_paths(publication_root)
  dir.create(paths$data, recursive = TRUE, showWarnings = FALSE)
  dir.create(paths$manifests, recursive = TRUE, showWarnings = FALSE)

  # Typed, checksum-validated exports from the separate thesis operation.
  transects <- readRDS(paths$input)
  legacy_total_load <- readRDS(paths$legacy_load_input)
  ids <- publication_fuel_ids

  # Keep the field measurements intact for audit. Post-PCT forest-floor values
  # are retained here but deliberately receive no duff/litter load conversion.
  forest_floor_station <- transects |>
    select(phase, all_of(ids), matches("^(duff_litter|pct_litter|fbd)[12]$")) |>
    pivot_longer(
      cols = matches("^(duff_litter|pct_litter|fbd)[12]$"),
      names_to = c(".value", "station"),
      names_pattern = "(.*?)([12])$"
    ) |>
    transmute(
      phase,
      across(all_of(ids)),
      station = as.integer(station),
      total_forest_floor_depth_cm = duff_litter,
      estimated_litter_fraction = pct_litter / 100,
      estimated_litter_depth_cm = total_forest_floor_depth_cm *
        estimated_litter_fraction,
      estimated_duff_depth_cm = total_forest_floor_depth_cm -
        estimated_litter_depth_cm,
      fuel_bed_depth_cm = fbd,
      forest_floor_load_eligible = phase == "prepct"
    )

  if (
    any(
      forest_floor_station$estimated_litter_fraction < 0 |
        forest_floor_station$estimated_litter_fraction > 1,
      na.rm = TRUE
    )
  ) {
    stop("Estimated litter fractions fall outside [0, 1].")
  }

  # Finney and Martin's cumulative curve partitions the pre-PCT total profile at
  # the estimated litter/duff boundary. These are model-derived loads, not direct
  # independent bulk-density measurements of the two layers.
  forest_floor_pre_station <- forest_floor_station |>
    filter(forest_floor_load_eligible) |>
    mutate(
      total_forest_floor_load_mgha = finney_martin_cumulative_load(
        total_forest_floor_depth_cm,
        total_forest_floor_depth_cm
      ),
      litter_load_mgha = finney_martin_cumulative_load(
        estimated_litter_depth_cm,
        total_forest_floor_depth_cm
      ),
      litter_load_raw_mgha = litter_load_mgha,
      litter_load_bounded_at_zero = litter_load_raw_mgha < 0,
      litter_load_mgha = pmax(litter_load_raw_mgha, 0),
      duff_load_mgha = total_forest_floor_load_mgha - litter_load_mgha
    )

  if (any(forest_floor_pre_station$duff_load_mgha < 0, na.rm = TRUE)) {
    stop(
      "Finney-Martin component calculation produced a negative duff load; inspect the input depths before proceeding."
    )
  }

  forest_floor_components <- forest_floor_pre_station |>
    select(phase, all_of(ids), station, litter_load_mgha, duff_load_mgha) |>
    pivot_longer(
      cols = ends_with("_load_mgha"),
      names_to = "component",
      values_to = "load_mgha"
    ) |>
    mutate(
      component = recode(
        component,
        litter_load_mgha = "litter",
        duff_load_mgha = "duff"
      ),
      derivation = "Finney-Martin 1993 model 3 cumulative-load partition"
    ) |>
    summarise(
      n_stations = sum(!is.na(load_mgha)),
      load_mgha = mean(load_mgha),
      derivation = first(derivation),
      .by = c(all_of(ids), "phase", "component")
    )
  saveRDS(
    forest_floor_station,
    file.path(paths$data, "forest-floor-measurements-station.rds")
  )
  saveRDS(
    forest_floor_pre_station,
    file.path(paths$data, "forest-floor-pre-components-station.rds")
  )
}

We’ll keep woody and herbacaceos vegetation separate, so herbaceous loads aren’t overwheled – they have very different implications for fire. We’ll convert cover and height using the thesis bulk densities, which used values from the firemon database manual, these should still be interpreted as operational convenience values rather than verified representative values for our systems. We’ll average the two stations within each transect. The displayed records show the loads and available station counts; a missing station leaves the transect mean missing. This review reads the combined component table saved in the next step.

To examine woody vegetation change, we need the two measurements from the same transect. We’ll match their identifiers before calculating pre-PCT minus post-PCT load. The pairing audit shows how many records can support that comparison and whether any are unmatched. This difference is an indicator of potential surface-fuel contribution; the measurements do not directly quantify deposited slash.

Code 
# f01-01-pair-transects
if (recompute) {
  # Explicit pre/post joins replace the thesis-era lexical phase ordering used to
  # construct veg_diff. The primary PCT contrast is woody standing vegetation
  # reduction; it is an inferred surface-fuel contribution, not direct slash load.
  vegetation_wide <- fuel_components_transect |>
    filter(component %in% c("woody_vegetation", "herbaceous_vegetation")) |>
    select(all_of(ids), phase, component, load_mgha) |>
    pivot_wider(
      names_from = c(component, phase),
      values_from = load_mgha,
      names_sep = "_"
    )

  fuel_bed_depth_phase <- forest_floor_station |>
    summarise(
      n_fuel_bed_stations = sum(!is.na(fuel_bed_depth_cm)),
      fuel_bed_depth_cm = mean(fuel_bed_depth_cm),
      .by = c("phase", all_of(ids))
    ) |>
    pivot_wider(
      names_from = phase,
      values_from = c(fuel_bed_depth_cm, n_fuel_bed_stations),
      names_sep = "_"
    )

  fuel_paired_transect <- vegetation_wide |>
    filter(
      !is.na(woody_vegetation_prepct),
      !is.na(woody_vegetation_postpct)
    ) |>
    inner_join(fuel_bed_depth_phase, by = ids) |>
    mutate(
      woody_standing_reduction_mgha = woody_vegetation_prepct -
        woody_vegetation_postpct,
      herbaceous_vegetation_change_mgha = herbaceous_vegetation_postpct -
        herbaceous_vegetation_prepct,
      interpretation = "Woody standing-vegetation reduction is an inferred potential surface-fuel contribution; it is not a direct slash-load measurement."
    )

  pairing_qc <- bind_rows(
    transmute(
      distinct(
        filter(vegetation_wide, !is.na(woody_vegetation_prepct)),
        across(all_of(ids))
      ),
      status = "pre-PCT woody observation"
    ),
    transmute(
      distinct(
        filter(vegetation_wide, !is.na(woody_vegetation_postpct)),
        across(all_of(ids))
      ),
      status = "post-PCT woody observation"
    ),
    transmute(
      anti_join(
        distinct(
          filter(vegetation_wide, !is.na(woody_vegetation_prepct)),
          across(all_of(ids))
        ),
        distinct(
          filter(vegetation_wide, !is.na(woody_vegetation_postpct)),
          across(all_of(ids))
        ),
        by = ids
      ),
      status = "pre-PCT woody observation without post-PCT match"
    ),
    transmute(
      anti_join(
        distinct(
          filter(vegetation_wide, !is.na(woody_vegetation_postpct)),
          across(all_of(ids))
        ),
        distinct(
          filter(vegetation_wide, !is.na(woody_vegetation_prepct)),
          across(all_of(ids))
        ),
        by = ids
      ),
      status = "post-PCT woody observation without pre-PCT match"
    ),
    transmute(
      distinct(fuel_paired_transect, across(all_of(ids))),
      status = "matched woody pair"
    )
  ) |>
    count(status, name = "n_transects")
  saveRDS(
    fuel_paired_transect,
    file.path(paths$data, "fuel-paired-transect.rds")
  )
  write_csv(pairing_qc, file.path(paths$data, "fuel-pairing-qc.csv"))
}

Fitting and residual-check functions

To compare candidates fairly, we’ll define fit_and_diagnose() to give each one the same fitting record and residual checks. When called, it reads the candidate’s saved model through read_saved_model() unless refit:true explicitly requests the optimizer and saves a replacement fit. It retains warnings and convergence information and adds simulation-based diagnostics, returning one register row per attempt. Those fields help us distinguish a promising AIC from a fit that still needs work. Sections 03 and 04 call this function during recompute or refit; an ordinary review render reads their saved registers instead.

Small label helpers describe formulas and family objects directly, so each candidate only needs to specify its model components. The optional family_label, ziformula_label, and dispformula_label arguments can still supply display text. In particular, ziGamma() identifies itself as "Gamma" inside its family object, so we keep its explicit label to distinguish that constructor. We also retain the Gaussian and Student-t display names.

Code 
# f01-fit-and-diagnose
# Create and return the model and diagnostic output folders.
model_output_paths <- function(paths) {
  models <- file.path(paths$output, "models")
  diagnostics <- file.path(paths$output, "diagnostics")
  dir.create(models, recursive = TRUE, showWarnings = FALSE)
  dir.create(diagnostics, recursive = TRUE, showWarnings = FALSE)
  list(models = models, diagnostics = diagnostics)
}

# Extract test results, retaining errors so other checks can continue.
extract_test <- function(test_fun, simulation) {
  result <- tryCatch(test_fun(simulation), error = function(error) error)
  if (inherits(result, "error")) {
    return(list(
      statistic = NA_real_,
      p_value = NA_real_,
      error = conditionMessage(result)
    ))
  }
  list(
    statistic = unname(result$statistic)[1],
    p_value = result$p.value,
    error = NA_character_
  )
}

# Keep formulas on one line, preserving operators and quoted variable names.
default_formula_label <- function(formula, label = NULL) {
  if (!is.null(label)) return(label)
  paste(trimws(deparse(formula, width.cutoff = 500L)), collapse = " ")
}

# Use family metadata rather than the expression or variable passed by a caller.
default_family_label <- function(family, label = NULL) {
  if (!is.null(label)) return(label)
  paste0(family$family, "(link = ", family$link, ")")
}

fit_and_diagnose <- function(
  model_id,
  response,
  analysis,
  data,
  formula,
  family,
  ziformula,
  dispformula,
  paths,
  simulation_n,
  simulation_seed,
  family_label = NULL,
  ziformula_label = NULL,
  dispformula_label = NULL
) {
  output_paths <- model_output_paths(paths)
  warnings <- character()
  fit <- if (isTRUE(params$refit)) {
    tryCatch(
      withCallingHandlers(
        glmmTMB::glmmTMB(
          formula = formula,
          data = data,
          family = family,
          ziformula = ziformula,
          dispformula = dispformula
        ),
        warning = function(warning) {
          warnings <<- c(warnings, conditionMessage(warning))
          invokeRestart("muffleWarning")
        }
      ),
      error = function(error) error
    )
  } else {
    read_saved_model(
      file.path(output_paths$models, paste0(model_id, ".rds")),
      "F01"
    )
  }

  # Fitting warnings are saved evidence; refreshing residuals must retain them.
  if (!isTRUE(params$refit)) {
    saved_register <- read.csv(file.path(
      paths$manifests,
      "model-comparison.csv"
    ))
    warnings <- stats::na.omit(saved_register$warnings[
      saved_register$model_id == model_id
    ])
  }

  base_record <- tibble::tibble(
    model_id = model_id,
    response = response,
    analysis = analysis,
    n = nrow(data),
    fixed_and_random_formula = default_formula_label(formula),
    family = default_family_label(family, family_label),
    ziformula = default_formula_label(ziformula, ziformula_label),
    dispformula = default_formula_label(dispformula, dispformula_label),
    fit_status = if (inherits(fit, "error")) "error" else "fit",
    fit_message = if (inherits(fit, "error")) {
      conditionMessage(fit)
    } else {
      NA_character_
    },
    warnings = if (length(warnings)) {
      paste(unique(warnings), collapse = " | ")
    } else {
      NA_character_
    },
    pd_hessian = NA,
    aic = NA_real_,
    dharma_uniformity_p = NA_real_,
    dharma_dispersion_p = NA_real_,
    dharma_outlier_p = NA_real_,
    dharma_zero_inflation_p = NA_real_,
    diagnostic_message = NA_character_
  )

  if (inherits(fit, "error")) {
    return(base_record)
  }

  if (isTRUE(params$refit)) {
    saveRDS(fit, file.path(output_paths$models, paste0(model_id, ".rds")))
  }
  simulation <- tryCatch(
    publication_simulate_residuals(
      fit,
      n = simulation_n,
      seed = simulation_seed
    ),
    error = function(error) error
  )
  if (inherits(simulation, "error")) {
    return(dplyr::mutate(
      base_record,
      pd_hessian = fit$sdr$pdHess,
      aic = stats::AIC(fit),
      diagnostic_message = conditionMessage(simulation)
    ))
  }

  # Some DHARMa tests may draw internally. Use a null device so these
  # exploratory diagnostics never create an incidental Rplots.pdf in analysis/.
  grDevices::pdf(file = NULL)
  on.exit(grDevices::dev.off(), add = TRUE)
  uniformity <- extract_test(DHARMa::testUniformity, simulation)
  dispersion <- extract_test(DHARMa::testDispersion, simulation)
  outliers <- extract_test(DHARMa::testOutliers, simulation)
  zero_inflation <- extract_test(DHARMa::testZeroInflation, simulation)

  png(
    filename = file.path(
      output_paths$diagnostics,
      paste0(model_id, "-dharma.png")
    ),
    width = 1800,
    height = 900,
    res = 150
  )
  plot(simulation)
  dev.off()

  dplyr::mutate(
    base_record,
    pd_hessian = fit$sdr$pdHess,
    aic = stats::AIC(fit),
    dharma_uniformity_p = uniformity$p_value,
    dharma_dispersion_p = dispersion$p_value,
    dharma_outlier_p = outliers$p_value,
    dharma_zero_inflation_p = zero_inflation$p_value,
    diagnostic_message = paste(
      stats::na.omit(c(
        uniformity$error,
        dispersion$error,
        outliers$error,
        zero_inflation$error
      )),
      collapse = " | "
    )
  )
}

04 - Fit matched woody candidates

Without a defensible post-PCT slash-depth conversion, the change in standing woody load offers one way to explore PCT’s potential contribution to surface fuels. We’ll compare a model of the paired differences with a joint model of the two phases. Woody loads are nonnegative, include zeros, and can be strongly right-skewed. A difference between two such loads can be negative, zero, or positive, with a distribution unlike either phase alone. Modeling the loads jointly respects their original scale and supplies both phase estimates. Modeling the observed differences directly asks whether a simpler change response gives a defensible account of the same paired data. These alternatives test different distributional and variance assumptions; they do not change the definition of woody reduction.

For transect \(i\), the observed signed difference is \(d_i = y_{i,\mathrm{pre}} - y_{i,\mathrm{post}}\). Positive values indicate less standing woody vegetation after PCT; negative values indicate more. Here, “signed-difference model” means fitting \(d_i\) directly, while “contrast from the joint phase model” means subtracting its two fitted response-scale means. Both yield signed changes in Mg/ha; a contrast is a derived quantity, not a separate response family.

Feature Joint phase model and derived contrast Direct signed-difference model
Response Two woody loads per matched transect, one per phase. One observed pre-minus-post difference per matched transect.
Treatment effects phase * treatment allows phase change to vary by treatment. treatment allows the difference to vary by treatment.
Distribution A zero probability plus a Gamma distribution for positive loads, with a log link. Gaussian or Student-t with an identity link, allowing either sign.
Pairing and design Site, block, and corner random intercepts, plus a shared transect intercept linking the two phases. Pairing is already used in the subtraction; site, block, and corner random intercepts retain clustering among differences.
Available estimates Pre- and post-PCT mean loads and their covariance-aware difference. Treatment-specific differences; the two phase means cannot be recovered from differences alone.

For the joint model, RD04 derives \(\Delta_t = \mu_{\mathrm{pre},t} - \mu_{\mathrm{post},t}\) from means that include the zero probability and integrate over the fitted random effects, with equal study-site weights. Exponentiating a phase contrast on the log scale would instead give a ratio in the positive-load submodel. The uncertainty of the response-scale difference retains the covariance between the estimated phase means: \(\operatorname{Var}(\hat\Delta_t) = \operatorname{Var}(\hat\mu_{\mathrm{pre},t}) + \operatorname{Var}(\hat\mu_{\mathrm{post},t}) - 2\operatorname{Cov}(\hat\mu_{\mathrm{pre},t},\hat\mu_{\mathrm{post},t})\). The direct model represents paired change through the distribution of \(d_i\) itself. Although \(E(Y_{\mathrm{pre}}-Y_{\mathrm{post}}) = E(Y_{\mathrm{pre}})-E(Y_{\mathrm{post}})\) when the means exist, separately fitted models need not give identical estimates or intervals because their assumptions and use of the phase information differ.

The three joint candidates use a common zero probability and dispersion, a phase-specific zero probability, or phase-specific dispersion. These distinguish changes in the frequency of absent woody vegetation from changes in the spread of positive loads. The six direct candidates use Gaussian errors with common or treatment-specific dispersion, or Student-t errors with common, treatment, additive treatment-plus-site, or treatment-by-site dispersion. Student-t provides heavier tails for unusually large changes; the dispersion alternatives assess whether residual spread differs among treatments and sites. No zero-inflation submodel is used for the signed response: a zero difference means equal phase loads, not necessarily absent woody vegetation. The family and submodel definitions follow the glmmTMB family documentation and fitting documentation.

The current saved fits use 234 phase-load observations or 117 paired differences. Their likelihoods describe different responses, so AIC is compared within each approach, not across the two approaches, following the same-data requirement for AIC. Convergence and residual checks still determine what needs follow-up. RD04 uses the joint model so its displayed woody change agrees with its phase means; the direct models remain sensitivity candidates. Neither approach establishes a causal PCT effect or measures slash production directly.
